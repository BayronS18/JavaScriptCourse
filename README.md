# JavaScript Fundamentals & Modern ES6+ Course

Repositorio con ejercicios prácticos, proyectos integradores y conceptos fundamentales del lenguaje JavaScript.

## Conceptos y Tecnologías Aplicadas
- **Fundamentos ES6+:** Variables (`const`, `let`), arrow functions, desestructuración y operador spread/rest.
- **Manipulación del DOM:** Selección de elementos, eventos, manejo de clases y validación de formularios.
- **Manipulación de Arreglos y Objetos:** Métodos iterativos (`map`, `filter`, `reduce`, `find`, `some`).
- **Asincronía y APIs:** Promesas, `async/await`, peticiones HTTP con `fetch` API y manejo de JSON.
- **Programación Orientada a Objetos (POO):** Clases, métodos, herencia y encapsulamiento.
